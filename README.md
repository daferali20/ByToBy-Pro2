# ByToBy Pro2 AI

منصة تحليل أسهم متقدمة باستخدام الذكاء الاصطناعي

## المميزات

- 🤖 تحليل ذكي للأسهم باستخدام الذكاء الاصطناعي
- 📊 فلترة متقدمة للأسهم مع اكتشاف الفرص
- 📈 إدارة المحافظ الاستثمارية بشكل احترافي
- 🔔 تنبيهات وإشعارات فورية
- 📰 تحليل الأخبار والمشاعر
- 🎯 تقييم القيمة العادلة للأسهم
- 💧 تحليل السيولة والأموال الذكية
- 🧠 نماذج تنبؤ وتصنيف متقدمة

## متطلبات التشغيل

- Python 3.10+
- Node.js 18+
- Docker & Docker Compose
- PostgreSQL 15+
- Redis 7+
